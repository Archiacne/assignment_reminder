# 作业提醒

一个 Edge / Chrome 扩展，定时检查 Moodle 类课程页面的“作业”章节，并在发现新作业时发送系统通知。

## 隐私与数据保存位置

扩展不收集账号、密码或 Cookie，也不使用分析、遥测或云端接口。登录由课程网站和 Edge 自己管理。

### 不启用本地辅助程序时

课程配置和已选择保存的作业记录位于当前 Edge 用户配置的 `chrome.storage.local` 数据库中。Windows 上的文件目录通常是：

```text
%LOCALAPPDATA%\Microsoft\Edge\User Data\<配置名称>\Local Extension Settings\<扩展ID>\
```

这是 Edge 管理的 LevelDB 数据，不是普通 JSON 文件，不建议直接编辑，也不会写入本项目的 `assignment` 文件夹。

- “保存新发布作业到本地”关闭：不保存作业标题、说明、截止信息和具体作业网址。
- 选择“仅作业网址”：在 Edge 本地数据库中保存网址、发现时间和内部课程 ID。
- 选择“课程、内容和网址”：在 Edge 本地数据库中保存课程代号、标题、页面可见说明（最多 1000 字）、截止信息、网址和发现时间。

### 启用本地辅助程序时

扩展先保留上述 Edge 本地记录，然后通过 Edge Native Messaging 把同一条新作业记录导出为 UTF-8 JSON 文件：

```text
<项目目录>\assignment\
```

每项新作业对应一个文件，例如：

```text
20260927-163000123_00_课程A_第一次作业.json
```

辅助程序不开放网络端口，也不会联网。扩展无法连接辅助程序时，Edge 内部记录仍会保留，并在扩展面板显示导出失败状态。

“清空本地记录”只清除 Edge 数据库里的作业历史，不会删除已经导出的 JSON 文件。卸载辅助程序同样不会删除 `assignment` 文件。

## 安装扩展

1. Chrome 或 Edge 右上角打开 “ $\cdots$ -> 扩展 -> 管理扩展”
2. 开启“开发者模式”。
3. 点击“加载解压缩的扩展”，选择本项目目录。
4. 开启工具栏上的“本地作业提醒”。

需要 Edge / Chrome 116 或更高版本。

本版本加入了固定扩展 ID。如果曾加载过没有辅助程序的旧版本，请先在 `edge://extensions` 移除旧卡片，再重新“加载解压缩的扩展”。

## 安装项目目录导出辅助程序

辅助程序仅注册到当前 Windows 用户，不需要管理员权限。

如果使用过早期的 `homework` 目录版本，请重新运行安装程序；安装脚本会移除旧 Native Messaging 注册并切换到 `assignment` 目录，旧目录中的已有文件不会被自动迁移或删除。

简便方式：双击项目根目录中的：

```text
install-helper.cmd
```

也可以在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\helper\install.ps1"
```

安装脚本会：

1. 使用 Windows 自带的 .NET Framework C# 编译器生成本地辅助程序；
2. 在当前用户的 Edge Native Messaging 注册表项中注册辅助程序；
3. 在当前项目下创建 `<项目目录>\assignment` 目录。

随后：

1. 在 `edge://extensions` 中重新加载扩展；
2. 打开扩展面板并开启“保存新发布作业到本地”；
3. 开启“同时导出到项目 assignment 文件夹”；
4. 批准 Edge 显示的“与本机应用通信”权限；
5. 点击“测试辅助程序”，确认显示连接成功。

卸载辅助程序注册信息可以双击 `uninstall-helper.cmd`。卸载不会删除已导出的作业文件。

## 添加课程

1. 页面右上角点击“扩展”，找到“本地作业提醒”，点击“固定到工具栏”，左侧就会出现对应图标
2. 登录课程网站。
3. 进入该课程的作业模块，例如 `example.edu/course/view.php?id=123/section-3`，复制地址栏中的**完整网址**。
4. 填写一个课程代号并粘贴网址。
5. 点击“授权并添加”，再点“立即检查”，就会出现已有作业数量。再点“打开”，就能来到作业网站（登录状态未失效）。

首次检查会显示已有作业数量。若想要定时检查，Edge 必须保持运行。

扩展会优先扫描 `#section-3` 指定的章节；没有章节锚点时，会查找标题为“作业”的章节。

## 移除数据

- 扩展中的“本地记录 → 清空”：只删除 Edge 内部作业历史。
- 删除课程：删除该课程配置和 Edge 内部历史，并撤销不再使用的网站权限。
- `uninstall-helper.cmd`：移除 Native Messaging 注册，不删除导出的 JSON。
- 导出的 JSON：需要由用户自行从 `<项目目录>\assignment` 删除。
